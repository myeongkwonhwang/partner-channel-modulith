### ③ 테스트 설계 정밀화 (계획 대비)

NAVER fake 빈은 TOSS 빈(휴면, 키 충돌 없음)과 공존하며 라우팅이 NAVER 라 외부 HTTP 미호출. saga 는 Phase 2 에서 채널 불문이라 비동기·Tx·outbox 검증에 충분.

- `Validator` = `@MockitoBean`(단일 public 빈, 레지스트리 무관) — 기본 PASSED, REJECTED 유도.
- 발행은 `TransactionTemplate` 안에서(`@ApplicationModuleListener` 발동 전제 = 활성 Tx).
- **플래키 교정**: `untilAsserted` 람다 안 `findByCorrelationKey(ck).orElseThrow()` 가 `NoSuchElementException` → Awaitility 는 `AssertionError` 만 무시 → 즉시 실패. AssertJ `Optional` 단언(`hasValueSatisfying`)으로 교정(빈 값=AssertionError=재시도). 3/3 안정.
